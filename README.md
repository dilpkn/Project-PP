# Приложение для промышленного программирования

Это приложение на Java предназначено для работы с файлами в различных форматах (`TXT`, `XML`, `JSON`). Оно поддерживает шифрование, дешифрование, архивирование и разархивирование, а также обработку математических выражений.

---

## 🚀 Возможности
- **Поддержка форматов файлов**: Работа с файлами `TXT`, `XML`, `JSON`.
- **Шифрование/дешифрование**: Реализовано на основе алгоритма AES.
- **Архивирование/разархивирование**: Поддержка сжатия и распаковки файлов в формате ZIP.
- **Обработка выражений**: Вычисление математических выражений с использованием регулярных выражений.
- **Графический интерфейс**: Удобный интерфейс, построенный на базе JavaFX.

---

## 🛠️ Используемые технологии
- **Java**: Основной язык программирования.
- **JavaFX**: Фреймворк для построения графического интерфейса.
- **JUnit 5**: Фреймворк для модульного тестирования.
- **Пользовательские библиотеки**: Для работы с файлами, шифрования и обработки выражений.

---

## 📂 Структура проекта
- `Controller.java`: Основной класс, реализующий логику приложения.
- `encryption.AESUtil`: Методы для шифрования и дешифрования данных с использованием AES.
- `expression.Regular`: Класс для обработки математических выражений с использованием регулярных выражений.
- `file_types`: Пакет с классами для работы с форматами `TXT`, `XML` и `JSON`.
- `archive.Compress_zip`: Утилиты для работы с ZIP-архивами.
- `src/main/resources`: Содержит FXML-файлы для графического интерфейса.
- `test/ControllerTest`: Модульные тесты для проверки шифрования, дешифрования и обработки выражений.

### 📋 Описание работы приложения  

#### Основной интерфейс  
Приложение предоставляет пользователю удобный графический интерфейс для работы с файлами и данными.  
Окно разделено на секции для выбора входного и выходного файлов, а также их настроек.  

#### Функциональные возможности  

- **Выбор формата файлов**:  
  - Входной и выходной файлы могут быть в формате `.txt`, `.xml` или `.json`.  

- **Указание имен файлов**:  
  - Поля ввода позволяют задать имена входного и выходного файлов.  

- **Обработка данных**:  
  Поддерживаются следующие операции:  
  - Распаковка архивов (*archived*).  
  - Запаковка файлов в архив (*archive*).  
  - Шифрование данных (*encrypt*).  
  - Дешифрование данных (*encrypted*).
